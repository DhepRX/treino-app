Backup dos treinos

Fora do Claude, os treinos ficam salvos só neste celular. Salve um backup de vez em quando e guarde no Arquivos, no iCloud Drive ou no WhatsApp.

Backup automático no GitHub

Configurar
  1. Crie um repositório privado chamado treino-dados, marcando Add a README file: github.com/new
  2. Crie uma chave em Fine-grained token. Em Repository access, escolha Only select repositories e o treino-dados. Em Permissions, ponha Contents em Read and write. Toque em Generate token e copie.
  3. Cole a chave aqui embaixo e toque em Ligar e testar.

A chave fica guardada só neste celular e só consegue mexer no repositório escolhido. Configure pelo app da Tela de Início, não pelo Safari.
